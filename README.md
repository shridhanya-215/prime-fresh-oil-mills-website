# Prime Fresh Oil Mills — Website Prototype

A responsive static website concept for a B2B edible-oil manufacturer.

## Features

- Responsive desktop and mobile layout
- Product catalogue featuring Yellow Mustard Oil
- Interactive Buyer Brief Planner
- Quotation enquiry form prototype
- Mobile navigation
- Premium green, gold and ivory visual design

## Files

- `index.html` — website structure and content
- `style.css` — visual design and responsive layout
- `script.js` — navigation, buyer planner and demo enquiry interactions

## Run locally

Open `index.html` in a browser. Keep all three website files in the same folder.

## Deploy with GitHub and Vercel

1. Create a GitHub repository named `prime-fresh-oil-mills-website`.
2. Upload all three website files and this README to the repository root.
3. In Vercel, import the GitHub repository.
4. Choose **Other** as the framework preset if prompted.
5. Leave the build command empty and deploy.

## Before launch

- Replace provisional stock images with official company and product assets where possible.
- Verify the company's official address, phone number and product catalogue.
- Confirm product specifications, packaging, certifications, minimum order quantities, pricing and lead times with the company.
- Connect and test a real form or email service before collecting enquiries.

**Important:** The current enquiry form is a frontend demonstration. It does not send or store customer information. Do not publish unverified company claims.
